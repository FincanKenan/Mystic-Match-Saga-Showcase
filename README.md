# 🧩 Mystic Match Saga

**Published Mobile Puzzle Game | Unity & C#**

🎮 [Available on Google Play](GOOGLE_PLAY_LINK)

Mystic Match Saga is a mobile puzzle game developed with Unity and C# and published on Google Play.

The core gameplay is based on selecting available tiles, moving them into the slot area, and clearing matching sets of three before all available slots are filled.

---

## 🎥 Gameplay

Core interaction loop:

**select tile → move to slots → match 3 → clear**
